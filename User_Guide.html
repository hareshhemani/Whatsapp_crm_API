System Initialization & Setup

To begin using the CRM, you must configure your Meta Developer credentials in the environment settings.

Configuration

  • Locate the .env file in the root directory.
  • Insert your Permanent Access Token.
  • Provide your Phone Number ID from Meta Dashboard.
  • Set a unique Verify Token for webhook security.

Webhook Integration

  • Expose your local server using Ngrok (Port 8000).
  • Configure the Callback URL in Meta: https://your-url.ngrok.app/webhook/.
  • Subscribe to "messages" in the Webhook fields.

Message Reception

When a customer sends a message, Meta triggers your Webhook. The system creates the contact if new and stores the message in the database for real-time viewing.

AUTOMATION

Keyword Processing

After storing, the system parses the message against active Automation Rules. If a keyword is matched, an instant reply is sent via the WhatsApp API.

Contact Management

Efficiently manage your audience through multiple entry points.

Single Entry

Use the (+) icon to manually add a single contact with a specific name and tag.

Bulk CSV Import

Upload large contact lists using the Import icon. Ensure your CSV has columns for phone, name, and tags.

Contact Deletion

Select a contact and use the Trash icon in the chat header to perform a soft-delete from your CRM view.

Bulk Broadcast Marketing

Reach your entire audience or specific segments in one click using Meta Approved Templates.

  • Click the Megaphone icon in the sidebar.
  • Enter the approved Template Name (e.g., welcome_offer).
  • Apply a Tag Filter (e.g., Customer) to target specific groups.
  • The system loops through matching contacts and delivers the template message.

Meta Dashboard Operations

Message Template Creation

Templates must be approved by Meta before they can be sent via this CRM.

  1. Log in to Meta Business Suite.
  2. Navigate to All Tools > WhatsApp Manager > Message Templates.
  3. Click Create Template and choose your category (Marketing, Utility, or Authentication).
  4. Define your body text and use {{1}}, {{2}} for dynamic variables.
  5. Once Approved, copy the Template Name for use in the CRM Dashboard.

Troubleshooting & Best Practices

Common Issues

  • Token Expired: If messages stop sending, check if your Temporary Access Token has expired. Use a Permanent Token for production.
  • Webhook Not Receiving: Ensure your Ngrok URL is active and matches the URL in Meta's Webhook configuration.
  • Template Error: Verify that the template name and language code in the CRM exactly match the ones approved by Meta.

Best Practices

  • Privacy: Your data is stored locally in whatsapp_crm.db. Never share this file or your .env file.
  • Rate Limiting: When broadcasting to thousands, Meta may limit speed. The system handles this, but avoid sending identical marketing spam to unverified numbers.
  • Backups: Periodically back up your SQLite database file to prevent data loss.
